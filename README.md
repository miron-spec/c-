# LoveMatch — повна локальна програма

Це один готовий ASP.NET Core 8 проєкт: фронтенд + бекенд + SQLite база даних.

## Що працює
- Реєстрація та вхід через JWT.
- Особиста анкета: ім'я, вік, місто, стать, опис.
- До 3 фотографій профілю.
- Власні інтереси/теги.
- Реальні анкети з бази даних.
- Вхідні та надіслані симпатії.
- Взаємний лайк автоматично створює Match.
- Особисті чати після Match.
- Текстові повідомлення, фото та відео.
- Історія повідомлень зберігається в SQLite.
- Тестові анкети створюються автоматично.
- Оксана і Марина спочатку вже поставили лайк новому акаунту, тому можна одразу перевірити Match.
- Swagger API: http://localhost:5187/swagger

## Найпростіший запуск у Windows
1. Встановіть **.NET 8 SDK**, якщо його ще немає.
2. Двічі натисніть `StartLoveMatch.bat`.
3. Перший запуск виконає `dotnet restore`, створить `matchapp.db` і відкриє браузер на `http://localhost:5187`.
4. Зареєструйте новий акаунт. Пароль має бути від 8 символів.

## Запуск через Visual Studio
Відкрийте `LoveMatch.sln` або `MatchApp.Backend.csproj` і натисніть Run / F5.

## Дані
- База: `matchapp.db` у папці проєкту.
- Завантажені фото профілю: `wwwroot/uploads/profile`.
- Фото/відео з чатів: `wwwroot/uploads/chat`.

Щоб почати з чистої бази, закрийте сервер і видаліть `matchapp.db`.
