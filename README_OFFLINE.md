# LoveMatch — повністю локальна/offline версія

## Що працює без Internet

Після першого відновлення NuGet-пакетів програма працює локально:

- ASP.NET Core API — `http://localhost:5187`
- SQLite база даних — локальний файл
- фронтенд — з `wwwroot/index.html`
- JWT авторизація — локально
- анкети, лайки, Match — локально
- чати та історія повідомлень — локально
- фото/відео — локальна папка `wwwroot/uploads`
- SignalR — через localhost
- шрифти та стилі фронтенду не завантажуються з Internet

## Перший запуск

Потрібен .NET 8 SDK або Visual Studio з ASP.NET Core.

Якщо NuGet-пакети цього проєкту вже є на комп'ютері, `StartLoveMatch.bat` запускає програму через `dotnet run --no-restore` і Internet не потрібен.

Якщо це перший запуск на новому комп'ютері, .NET може потребувати один раз завантажити NuGet-пакети. Після успішного `restore` повторні запуски повністю offline.

## Запуск

Запусти:

`StartLoveMatch.bat`

або відкрий:

`LoveMatch.sln`

у Visual Studio і запусти `MatchApp.Backend`.

## Важливо

`localhost` — це не Internet. Браузер підключається тільки до програми на цьому ж комп'ютері.

Якщо Windows Firewall запитає дозвіл для dotnet, дозвіл для локальної мережі не є обов'язковим для звичайної роботи через `localhost`; головне, щоб локальний запуск на цьому ПК був дозволений.
