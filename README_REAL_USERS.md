# LoveMatch — реальні користувачі

У цій версії вимкнені всі демо-анкети та автоматичні демо-лайки.

- Новий користувач створюється тільки через реєстрацію.
- Анкета з'являється після заповнення профілю.
- Якщо підходящих реальних анкет немає, показується: «Наразі анкет для вас немає».
- Дані зберігаються у базі SQLite на сервері.

## Важливо для GitHub
GitHub Pages підходить для статичного frontend (HTML/CSS/JS), але ASP.NET Core API і SQLite не можуть працювати всередині GitHub Pages. Для реальних спільних користувачів API та база мають бути розміщені на окремому сервері/хостингу.
